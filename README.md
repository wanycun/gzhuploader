# 公众号助手（gzhuploader）

把 Markdown 文章排版后一键送进微信公众号草稿箱的飞牛 fnOS 应用。全部在本机运行：密钥、文章、图片只存在你自己的 NAS 上。

## 功能

- **文章包管理**：一篇文章一个包（Markdown + 封面 + 配图），标题、副标题（摘要）、封面在「编辑」页搞定
- **排版**：三套原创主题（电光蓝图 / 靛蓝档案 / 暖砂杂志），字号、间距、标题样式可调；正文与配图可在排版页直接修改
- **一键上传**：服务端排版 → 图片逐张传微信 → 进公众号草稿箱（自动开留言）；草稿箱可查可删
- **文案生成**：给一个主题，AI（DeepSeek）按你设置的账号口径出稿并自动建包
- **令牌 API**：`http://<NAS>:10039/api/v1`，带 Bearer 令牌即可建包、传图、排版、上传，供其他 AI / 脚本接入（应用内「设置 → 接入说明」有完整文档）
- **安装向导**：安装 / 升级时可直接填 AppID、AppSecret、DeepSeek Key，全部可留空，装完在设置页填也一样

## 安装

1. 下载 `fpk/` 目录里对应架构的安装包（x86 或 arm，认不准就下无架构后缀的那份）；
2. 飞牛应用中心 → 手动安装 → 选文件（手机端要在文件选择里点进文件夹选中文件本体，「已选择 1 项」后确定才可点）；
3. 向导里填公众号 AppID / AppSecret（可留空跳过）；
4. 打开应用，按仪表盘引导把 NAS 出口 IP 加进公众号 IP 白名单（微信公众平台 → 设置与开发 → 基本配置），否则上传报 40164。

AppID / AppSecret 在微信公众平台「设置与开发 → 基本配置」里。DeepSeek Key 只影响「文案生成」，不用可不填。

## 结构

- `app/server/serve.py`：应用本体（网关 + unix socket，纯 Python 标准库）
- `app/www/`：页面（仪表盘 / 文章包 / 编辑 / 文案生成 / 草稿箱 / 运行日志 / 设置 / 关于）
- `app/typeset/`：排版引擎（gzh-typeset）
- `wizard/`：安装 / 升级向导
- `cmd/`：fnOS 生命周期脚本
